Sensor in the feedback path

Log scale: 0.01 s to 10 s. The sensor is first order with gain 1: τs·dym/dt = y − ym. This is the same first-order sensor model as Homework 1 Module 1 (τẏ + y = Kx with K = 1), now placed inside the feedback loop.

Presets use K = 1, τ = 1 s, Kp = 1, Ki = 5, Kd = 0, where theory puts the edge of stability at τs = 0.667 s.

Plant and setpoint

Turn the limit off to see the linear loop the stability formulas describe: past the critical τs its oscillation grows without bound. With the limit on, the swing is capped and becomes a steady oscillation (a limit cycle).

PID controller

Error: e = r − ym  (the sensor reading, not y)
PID: u* = Kp·e + Ki·∫e dt − Kd·dym/dt
Actuator: u = clamp(u*, 0, 100 %)

The derivative acts on the sensor reading. Its slope is known exactly from the sensor equation, dym/dt = (y − ym)/τs, so no finite difference is needed. The integral stops growing while the actuator is pushed into a limit (anti-windup).

The sensor sits in the feedback path. The controller subtracts ym, not y, so it can only correct what the sensor reports.

Numerical model

τ·dy/dt = −y + K·u   (plant)
τs·dym/dt = y − ym   (sensor)
dI/dt = r − ym   (integral, paused by anti-windup)

The three states are stepped with the classical 4th-order Runge–Kutta method (RK4). Forward Euler was tried first, but it adds a small false growth to every oscillation (about h·ω²/2 per second), which shifts the edge of stability by a few percent; RK4 makes that error negligible. The time window follows the slower of τ and τs. Results are stored at about 2000 points, and each point is split into smaller steps when the loop is fast (h·rate ≤ 0.5).
