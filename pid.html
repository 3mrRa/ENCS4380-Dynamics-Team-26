Plant model

The plant input is the actuator command u (0–100%). Plant gain K maps this command to the output scale.

PID controller

PID: u* = Kp·e + Ki·∫e dt − Kd·dy/dt
Error: e = r − y
Actuator: u = clamp(u*, 0, 100%)

Derivative is applied to the measured output to avoid a derivative kick when the setpoint changes. For a step setpoint this equals Kd·de/dt everywhere except at t = 0. Integral accumulation is paused when saturation would drive the actuator further into its limit.

Metrics are calculated from the simulated output. Rise time, overshoot and settling time are measured against the final value y(∞); steady-state error is r − y(∞). Settling time is the first time after which the output remains within ±2% of y(∞). If it does not settle during the displayed simulation, it is reported as “Not settled”.

Numerical model

The differential equations are integrated using the forward Euler method. Results are plotted every 0.01 s; when the gains make the loop fast, each 0.01 s is split into smaller Euler steps so the integration stays stable and accurate. Change the plant and PID gains to see how the closed-loop response changes.
