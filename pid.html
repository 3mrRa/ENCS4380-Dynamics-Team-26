Plant model

The plant input is the actuator command u (0–100%). Plant gain K maps this command to the output scale, e.g. rpm per % PWM for a motor. Type measured values into the boxes for exact numbers.

PID controller

PID: u* = Kp·e + Ki·∫e dt − Kd·dy/dt
Error: e = r − y
Actuator: u = clamp(u*, 0, 100%)

Derivative is applied to the measured output to avoid a derivative kick when the setpoint changes. For a step setpoint this equals Kd·de/dt everywhere except at t = 0. Integral accumulation is paused when saturation would drive the actuator further into its limit.

Metrics are calculated from the simulated output. Rise time, overshoot and settling time are measured against the final value y(∞); steady-state error is r − y(∞). Settling time is the first time after which the output remains within ±2% of y(∞). If it does not settle during the displayed simulation, it is reported as “Not settled”.

Numerical model

The differential equations are integrated using the forward Euler method. The time window follows the plant's own time scale (τ, or 1/(ζωn)), so fast motors and slow heaters both fill the plot; results are plotted at about 2000 points, and when the gains make the loop fast each point is split into smaller Euler steps so the integration stays stable and accurate. Change the plant and PID gains to see how the closed-loop response changes.
